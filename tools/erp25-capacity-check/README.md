# Проверка выполнимости плана — ERP 2.5.22.186

Целевая конфигурация: **1С:ERP Управление предприятием 2, релиз 2.5.22.186**.

Обработка читает только типовые объекты:
- Документ.ПланПроизводства.Продукция
- Справочник.РесурсныеСпецификации / ЭтапыПроизводства
- Справочник.МаршрутныеКарты / ТехнологическиеОперации
- РегистрНакопления.ДоступностьВидовРабочихЦентров

Расчет:
1. строки плана сортируются по дате выпуска;
2. операции каждой спецификации строятся в порядке этапов и операций;
3. трудоемкость переводится в секунды;
4. свободная мощность ВРЦ = типовая доступность ERP минус уже занято;
5. операции последовательно резервируют свободную мощность;
6. выводится расчетная дата окончания, выполнимость и ограничивающий ВРЦ.

Сборка EPF выполняется GitHub Actions через v8unpack и обязательный round-trip.

Важно: runtime smoke-test на самой конфигурации 2.5.22.186 запускается отдельным job на self-hosted Windows runner с установленной платформой 1С.
